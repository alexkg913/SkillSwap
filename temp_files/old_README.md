## What is Skill Swap?

---

SkillSwap is an experimental web django project designed to connect struggling FSC students 
with peer tutoring opportunities on campus.

Students can discover existing tutoring resources, offering tutoring for courses they've already
completed, and connect with other students along the way!

---

## Planned Features

- Student accounts and profiles
- Search for tutors by course or subject
- Create tutoring offers and requests
- Student skill matching
- Tutoring session scheduling
- Tutor/student communication
- Canvas integration
- FSC campus tutoring events

## Django Design
SkillSwap is comprised into three primary Django applications:

### Student/Tutor Accounts
Authentication, student profiles, account management.

### Events
Tutor listings, tutoring events, searching, filtering.

### In-App Messaging
Establishes the communication between tutors and students.
